## string -> int

最直接的 C++11 写法：

```cpp
string s = "176";
int x = stoi(s);
```

用 `stringstream`：

```cpp
string s = "176";
stringstream ss(s);

int x;
ss >> x;
```

手写十进制解析：

```cpp
int x = 0;
for (char c : s) {
    x = x * 10 + (c - '0');
}
```

手写解析时要先确认输入只包含合法十进制数字；如果题目允许符号、空格或非法字符，需要单独处理。

## int -> string

```cpp
int x = 176;
string s = to_string(x);
```

或者：

```cpp
stringstream ss;
ss << x;
string s = ss.str();
```

## stringstream 怎么理解

`stringstream` 可以理解为“以字符串作为底层缓冲区的 `cin/cout`”。

- `ss << value`：像 `cout` 一样把内容写进流；
- `ss >> value`：像 `cin` 一样从流里解析内容；
- `ss.str()`：拿到流当前保存的字符串；
- `stringstream ss(s)`：用已有字符串初始化一个流。

## 整数格式化为十六进制

```cpp
int x = 176;
stringstream ss;
ss << uppercase << hex << setw(2) << setfill('0') << x;
string s = ss.str();  // B0
```

常用控制符：

- `hex`：十六进制输出；
- `dec`：恢复十进制输出；
- `uppercase`：A-F 使用大写；
- `setw(2)`：当前一次输出字段至少宽 2；
- `setfill('0')`：宽度不足时用 0 填充。

注意：`setw` 通常只作用于紧接着的一次格式化输出，不要把它误认为会永久固定宽度。

## IPv4 每段转两位十六进制

手写 `/16` 和 `%16` 完全合理：

```cpp
char toHex(int x) {
    if (x < 10) return '0' + x;
    return 'A' + (x - 10);
}

string byteToHex(int x) {
    string ans;
    ans += toHex(x / 16);
    ans += toHex(x % 16);
    return ans;
}
```

边界值至少回测：

```text
0   -> 00
9   -> 09
10  -> 0A
15  -> 0F
16  -> 10
255 -> FF
```

## 本次易错点

1. 不要因为知道手写转换原理，就忽略标准库提供的更稳实现；
2. 如果线上只通过一部分测试，先保存失败版本和完整题面，再定位隐藏边界，不要只凭记忆猜原因；
3. 进制转换题要把“数值正确”和“字符串格式正确”分开检查，例如位宽、前导零、大小写、前缀、多组输入等。
