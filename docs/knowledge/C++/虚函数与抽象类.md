## 我现在应该怎样理解

```cpp
struct IDevice {
    virtual void start() = 0;              // 纯虚函数
    virtual void stop() { /* 公共默认行为 */ } // 虚函数，非纯虚
    void resetCounter() { /* 普通成员函数 */ } // 非虚
    virtual ~IDevice() = default;           // 通过基类指针删除时确保析构正确
};

struct Camera : IDevice {
    void start() override { /* 启动摄像头 */ }
};

void launch(IDevice& d) { d.start(); }  // 调用依据对象的动态类型分派
```

这里 `IDevice` 即使有普通函数，仍因 `start() = 0` 是抽象类；`Camera` 只有在实现了所有继承的纯虚函数后才能实例化（如果它们没有已经在中间层获得最终覆写）。通过基类指针/引用调用 `virtual` 函数才是此处运行时多态的典型场景。大多数 C++ 实现用 vptr/vtable 实现，语言标准不强制规定内部必须采用虚表。

## 易错点

1. **有虚函数 ≠ 一定是抽象类**；**只有纯虚函数才保证抽象**（对继承而来的纯虚函数也算）。
2. **抽象类 ≠ 所有成员函数都是虚函数**；也不要求全部为纯虚。
3. `virtual ~Base()` 是安全使用多态基类常见要求；纯虚析构也需要提供定义。
4. 派生类对象按值复制进基类对象可能发生对象切片，不能假设依然根据原派生类型分派。

## 推荐面试口头回答

> 虚函数是在基类中用 virtual 声明的成员函数，派生类可以重写它。通过基类指针或引用调用时，会根据对象的实际动态类型执行对应的重写版本，这样就能用统一接口处理不同对象。纯虚函数用等于零声明；只要类含有未被最终覆写的纯虚函数，它就是抽象类，不能直接创建对象，但可以包含普通函数和成员变量。多态基类一般需要虚析构，避免通过基类指针删除派生类时产生问题。
