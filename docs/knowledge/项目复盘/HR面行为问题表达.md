## 我的现场问题

这场 HR 面通过，说明大的方向没有问题：我能解释教育背景、经纬恒润实习、V853 项目、为什么对影石相机业务感兴趣，也能表达至少三个月、最长六个月左右的实习时长。但是现场有几个表达习惯需要稳定下来：

1. 回答行为问题时，容易先讲经历，不先给判断标准。
2. 解释上一段实习结束原因时，说了“体验不同公司 / 不同硬件设备”，这会让 HR 担心稳定性。
3. 加班问题里，能表达“项目急可以理解”，但“没想好做什么，加班没有意义”这类话偏直接，应该换成“先同步下一步优先级”。
4. 影石岗位动机是成立的，但最好用“相机业务 + 摄像头采集 + 视频流 + 设备端 UI 状态逻辑”直接说明，不要绕太长的 OS 类比。

## 固定回答原则

HR 面不是要背标准答案，而是要让对方放心：

> 我知道自己为什么来；我能稳定投入；我能沟通风险；我不是只想短期混一段经历；我能把过往项目迁移到这个岗位。

回答结构尽量固定为：

> 结论一句话 → 真实原因两点 → 风险消除一句 → 岗位匹配一句。

如果问题涉及价值观或团队配合，比如加班、优先级、导师培养，不要先表达个人情绪，而是先讲“我怎么对齐目标、怎么判断优先级、怎么保证产出”。

## 场景 1：为什么上一段实习只做了四个月

**当时的风险表达：**

> 我想着可以体验一下不同公司、不同硬件设备上的软件开发。

这句话真实，但 HR 容易理解成“我来你们这边也只是体验一下”。更好的说法应该强调阶段性结束和方向匹配。

**推荐口头回答：**

上一段经纬恒润实习主要有两个原因结束。第一个是那段岗位本身更偏日常实习，当时没有明确转正机会；第二个是学校刚好有中期答辩节点，需要回校处理论文相关事项。那四个月里我已经比较完整地接触了 TBox 的车云通信、远控、车况上报和问题定位流程，所以不是因为不适应离开，而是阶段性实习目标完成后，再结合学校安排做了调整。

接下来如果加入贵司，我希望在更贴近设备端软件、相机业务和视频能力的方向继续沉淀，所以实习时间上我可以保证至少三个月，也可以根据项目安排尽量延长。

## 场景 2：给上一段实习打几分

**推荐口头回答：**

如果打分，我会给上一段实习打 8 分。分数比较高，是因为那段实习让我第一次比较系统地接触真实车载软件项目，包括 TBox 的车云通信、远控、车况上报和提测阶段的问题定位，也让我理解到车载设备对稳定性和安全性的要求。

没有打满分，是因为我也意识到自己还有两个提升点。第一个是表达和汇报能力，刚开始我容易把一个工作讲得太复杂，后来才逐渐学会先讲结果和价值；第二个是需求拆解能力，真实业务里不是写完代码就结束，还要理解需求边界、异常场景和测试验证。这两个点也是我下一段实习想继续提升的地方。

## 场景 3：你怎么安排优先级

**当时的风险表达：**

> 测试啊，或者说一些解 bug 的任务整体来说周期比较长，所以会在基本软件逻辑开发以后，如果有剩余时间，再对这些 bug 进行修复。

这句话的问题是容易把 bug 说成低优先级。更好的方式是先给排序维度。

**推荐口头回答：**

我一般会按四个维度排优先级：第一是交付节点，比如临近提测或版本发布的任务优先级最高；第二是阻塞关系，如果我的任务会影响别人继续开发或测试，就要先处理；第三是影响范围，涉及主链路、稳定性或用户可见问题的 bug 要优先；第四是任务确定性和耗时，如果是周期较长的问题定位，我会先拆成可验证的小步骤，避免一直卡住。

在实习里，我通常会结合每周例会确认周目标，每天早上再复盘前一天进展，列出当天必须完成、最好完成和可以延后的事项。如果遇到提测问题或阻塞性 bug，会及时和导师同步，而不是自己闷头排。

## 场景 4：你怎么看加班

**当时的风险表达：**

> 如果到了下班时间，工作基本完成，下一步也没想好，这种加班可能就有一点没有意义。

这个意思不一定错，但 HR 面不适合把重点放在“没意义”。更稳的表达是“加班要有明确目标，目标不明确时先同步优先级”。

**推荐口头回答：**

我对加班的理解是以项目目标和问题解决为导向。软硬件结合的项目在临近提测、发布或者遇到关键问题时，确实会有一些集中加班，这种我可以理解，也愿意配合，因为问题不解决会影响整体进度。

同时我也希望加班是有明确目标的，比如要完成某个版本节点、定位某个阻塞问题、配合测试回归。如果当天任务已经完成，后续目标也不明确，我会先和导师同步下一步优先级，看是否有需要补的测试、文档或复盘，而不是单纯坐时间。我更看重的是产出和责任，而不是形式上的时长。

## 场景 5：目前有其他流程 / offer，影石优先级如何

**推荐口头回答：**

我目前确实还有几个流程在推进，也有一些外地机会，但我个人会更倾向深圳。一方面我现在在深圳校区，暑期也基本会留在深圳；另一方面影石这个岗位和我做过的摄像头采集、视频流、设备端软件方向更匹配，所以在我这里优先级是比较高的。如果流程顺利，我会优先认真考虑影石这边。

如果 HR 问“排第几”，不要只说“很高”，可以说：

> 目前属于比较靠前的选择。因为它同时满足方向匹配、业务兴趣和地点匹配这三个条件。

## 场景 6：你能实习多久 / 问转正机会是否合适

问转正机会本身是可以的，但要避免显得“只看有没有转正”。更好的逻辑是：我希望确认长期发展可能性，但前提是先把实习做好。

**推荐口头回答：**

我理解您的顾虑，因为实习生如果时间太短，公司在培养和项目安排上确实会比较难做。我这边可以比较明确地保证至少三个月，如果项目节奏需要，我也可以尽量延长到六个月左右，并且会提前和导师沟通学校、秋招这些时间安排，避免影响项目交付。

我问转正机会，并不是只想把实习当成一个短期经历，而是希望确认如果双方匹配、我表现也符合要求，后续是否有继续发展的可能。影石的相机业务和我做过的摄像头采集、视频流、设备端软件比较相关，所以我对这个方向的兴趣是比较明确的，也希望实习期间能真正参与需求和项目，产出一些对团队有价值的工作。

## 易错点

- `[learning]` 不要用“体验不同公司”解释离职，容易削弱稳定性。
- `[learning]` 不要只说“优先级就是提测优先”，要补阻塞关系、影响范围、交付节点和耗时不确定性。
- `[learning]` 不要把 bug 放到“有剩余时间再修”，阻塞性 bug 往往是最高优先级。
- `[learning]` 不要在加班问题里把“无意义”展开太长，改成“先同步下一步优先级”。
- `[learning]` 不要把影石动机讲散，核心是相机业务、摄像头采集、视频流、设备端 UI 状态逻辑。
- `[learning]` 问培养流程时，不要显得等导师系统培训，要表达“我会主动看文档、读代码、从小需求和 bug 入手”。
