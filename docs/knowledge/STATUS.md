# 当前能力状态

这个页面不是题库，也不是完整知识目录，而是用于维护“接下来最值得复习什么”的轻量状态索引。

AI 在执行“模拟面试”“按知识库复习”时，应先读取本页，再根据条目中的链接或关键词去读取对应知识页、面试复盘和原始资料。

## 状态含义

- `[weak]`：不会、答错或明显薄弱，下一轮优先追问。
- `[learning]`：已经理解一部分，但回答还不稳定。
- `[mastered]`：能够独立解释，并能应对至少一层追问。
- `[wrong]`：曾经出现过明确错误理解，作为历史记录保留。
- `[interview]`：真实面试出现过。
- `[project]`：可以和自己的项目/实习建立连接。
- `[todo]`：需要后续补充或验证。

## 当前优先队列

> 初始状态页不根据历史聊天自动猜测掌握程度。下一次模拟面试、技术复习或面试复盘时，再把被实际验证的问题加入这里。

### Weak

- 暂无。出现明确不会、答错或无法继续追问的问题时加入。

### Learning

- 暂无。完成一次解释但仍不稳定的问题加入。

### Wrong history

- 暂无。明确出现错误理解时记录“错误点 → 修正结论 → 对应知识页”。

### Mastered sample pool

- 暂无。只有在能够独立回答并通过追问后再加入。

## 更新规则

1. 不因为“看过答案”就把状态升级为 `[mastered]`。
2. `weak → learning`：能用自己的话完整解释核心因果关系，但追问仍不稳定。
3. `learning → mastered`：至少在一次新的问答中独立回答正确，并通过一层以上追问。
4. 如果 `[mastered]` 后再次答错，可以降级；保留状态变化记录，不需要维持单向升级。
5. `[wrong]` 是历史标签，不因后续掌握而删除；可以同时存在 `[wrong] [mastered]`。
6. 每个状态条目尽量链接到 `docs/knowledge/` 的长期知识页；如果尚无知识页，先保留关键词，后续“沉淀一下”时补齐。
7. 一场面试只挑最影响结果的 2～3 个问题进入优先队列，避免本页膨胀成第二份题库。

## 推荐条目格式

```markdown
- [weak] task_struct 与内核栈关系
  - 来源：2026-09-xx 某次模拟面试
  - 知识页：[进程与线程](操作系统/进程与线程.md)
  - 卡点：能说出 task_struct 在内核空间，但解释不清 current 如何关联当前任务

- [learning] TCP 粘包与应用层消息边界
  - 来源：某次真实面试
  - 下一步：追问 length-prefix / delimiter / fixed-size framing 的取舍
```
