# 二叉树遍历、重建与快速自检

> 状态：`[weak]`  
> 标签：`[interview]`  
> 最近复习：2026-09-24

!!! question "面试问题"
    根据给定的前序和中序序列画二叉树，或者验证自己画出的树是否同时满足两组遍历条件。现场写完以后，怎样在几十秒内发现节点位置画错？

## 三种遍历先固定“根”的位置

- 前序：`根 → 左 → 右`，所以序列第一个元素是当前子树根。
- 中序：`左 → 根 → 右`，所以根把当前子树切成左、右两部分。
- 后序：`左 → 右 → 根`，所以序列最后一个元素是当前子树根。

不要只背顺序，要把它转成重建时可执行的动作：**从前序取根，到中序找根，按中序左右区间的长度切分前序，再递归。**

## 前序 + 中序重建的稳定步骤

假设节点值唯一：

1. `preorder[preL]` 是当前根；
2. 在 `inorder` 当前区间找到根的位置 `k`；
3. 左子树节点数 `leftSize = k - inL`；
4. 左子树使用：
   - 前序 `[preL + 1, preL + leftSize]`
   - 中序 `[inL, k - 1]`
5. 右子树使用：
   - 前序 `[preL + leftSize + 1, preR]`
   - 中序 `[k + 1, inR]`
6. 对左右区间递归。

核心不是画图直觉，而是每次都让两份序列的子树节点集合和长度严格对应。

## 现场 30 秒自检法

画完树以后，不要继续盯着原推导。直接从成品树重新走一遍：

1. 写出前序：先根，再完整走左子树，最后完整走右子树；
2. 写出中序：先完整走左子树，再根，最后完整走右子树；
3. 与题目逐位比较，找到第一个不一致的位置；
4. 如果第一个不一致节点在中序中位于某个父节点左侧，却被画在右子树，优先检查左右子树归属；
5. 再检查两个序列是否包含完全相同的节点集合和节点数。

这种 round-trip 自检比重新按原思路看一遍更容易发现错误。

## 一眼就能检查的局部约束

对于当前根 `r`：

- 中序中 `r` 左边的所有节点只能出现在 `r` 的左子树；
- 中序中 `r` 右边的所有节点只能出现在 `r` 的右子树；
- 前序中紧跟在 `r` 后的节点，如果左子树非空，就是左子树根；
- 切分出的前序左区间与中序左区间必须是同一组节点；右区间同理。

如果题目节点值不唯一，仅靠前序和中序通常不能唯一重建，需要额外标识或条件；面试时应先确认节点是否唯一。

## 本场证据边界

录音只保留了面试官让用户重新口述前序、中序并指出“与题目条件有点问题”的过程。节点字母在 ASR 中出现重复、错字和缺失，屏幕上的原题、树图及完整序列都没有进入转写。因此不能根据录音补造正确树，也不能确定究竟是哪一个节点放错。

能够确认的是：现场没有通过重新遍历及时发现不一致，说明“画树后的 round-trip 自检”尚未形成习惯。

!!! warning "我容易答错的地方"
    - `[weak]` 画完以后凭图形感觉确认，没有重新生成前序和中序逐位核对。
    - `[weak]` 只记“前根、中根、后根”的位置，却没有用中序区间确定左右子树节点集合。
    - `[weak]` 转写缺失时容易事后猜正确树；复盘必须明确标记题面缺失，不能制造现场答案。

## 推荐口头回答

> 我会先用前序第一个节点确定根，再在中序中找到根，把中序切成左右子树。左子树的节点数决定前序里左子树区间的长度，然后递归构造左右子树。画完后我会从结果树重新写一遍前序和中序，与题目逐位核对；如果不一致，就从第一个不同节点回到对应子树检查左右归属。这个方法的前提是节点值唯一，否则两种遍历不一定能唯一确定一棵树。
