- 现场问题：手机在 4G/5G 网络下点开一个视频，从 App 到视频显示，数据经过哪些主要步骤？

## 现场暴露

我把这道题先误判成 Android 平台题，只回答了“客户端向爱奇艺服务器发请求，服务器持续推流”。这只覆盖应用层表象，漏掉了面试官真正想听的完整链路：

> 蜂窝网络已接入 → DNS → TCP/QUIC → TLS/HTTP → IP → Modem → 基站 → 核心网 → 公网/CDN/服务器 → 返回 → 缓冲/解码/渲染

这不是单个八股知识点，而是把简历中的 TCP、HTTP、TBox 和无线通信串成一条系统链路的能力。

## 我的理解

回答这类题要先声明前提，再按层向下讲，最后沿反向链路返回。

### 前提 1：手机已经有蜂窝数据网络

“已经有网”意味着手机与运营商网络之间已经完成一系列接入过程，例如：

1. SIM/USIM 身份与鉴权；
2. 搜网、驻留和注册；
3. 建立数据连接或会话；
4. 获得 IP 地址、DNS 等网络配置；
5. 系统中出现可供应用使用的蜂窝数据网络接口和路由。

面试第一轮不必展开所有 4G/5G 信令，但要知道 DNS、TCP 和 HTTP 发生之前，设备必须先完成蜂窝接入并具备 IP 连通性。

### 应用到服务器的主链路

1. **业务定位目标**：App 根据视频 ID 获取播放地址或 CDN URL。
2. **DNS**：把域名解析为 CDN / 服务器 IP；可能先查本地缓存，再向配置的 DNS 解析器查询。
3. **建立传输连接**：
   - HTTPS over TCP：先 TCP 三次握手，再 TLS 握手；
   - HTTP/3：通常使用 UDP 上的 QUIC，把传输安全与连接建立结合起来。
4. **应用层请求**：发送 HTTP 请求，获取清单、鉴权信息或视频分片。
5. **协议栈封装**：应用数据向下经过传输层、IP 层和蜂窝数据接口。
6. **Modem 与空口**：Modem 依据当前承载和无线资源处理数据，经射频链路发给基站。
7. **运营商网络**：基站把流量送到核心网，核心网完成用户数据转发并把流量送入承载网/公网。
8. **CDN/服务器**：目标服务处理请求并返回视频清单或分片。
9. **反向返回**：数据沿服务器 → 公网/运营商网络 → 核心网 → 基站 → Modem → 主机协议栈 → App 返回。
10. **播放**：播放器做缓冲、解封装、解码、音视频同步和渲染。

## Modem 在链路中的边界

不要把 Modem 简化成“有一个 4G/5G 模组，所以系统自动就能上网”。

模组或 Modem 侧通常承载蜂窝接入、空口协议和数据面处理；主机侧仍可能需要：

- 模组上电、复位、初始化和状态监控；
- SIM、信号、注册和数据会话状态管理；
- 通过 AT、QMI、MBIM 或厂商接口控制模组，具体方式依平台而异；
- 建立并维护主机侧网络接口；
- 配置 IP、DNS、路由和策略路由；
- 处理掉网、重拨、切网、漫游、弱网和异常恢复；
- 把网络状态提供给 Android、TBox 应用或上层中间件。

我在 TBox 实习中的真实边界是网络可用之后的 Linux 应用层协议，包括 TCP 连接之上的登录、心跳、数据上报和响应解析；没有亲手负责 Modem 协议栈、拨号或蜂窝数据会话。

## 容易混淆的层次

| 层次 | 典型内容 | 面试易错点 |
| --- | --- | --- |
| 业务/应用 | 视频 ID、播放 URL、清单、分片、鉴权 | 只说“发请求、服务器推流” |
| DNS | 域名到 IP | 忘记访问域名之前先解析 |
| 传输/安全 | TCP/QUIC、TLS、拥塞控制 | 把 TCP、TLS、HTTP 顺序混在一起 |
| IP/路由 | 目标 IP、路由、分片/MTU | 只背协议名，不知道数据向下封装 |
| 蜂窝接入 | Modem、基站、无线资源 | 把 Modem 当成普通网卡黑盒 |
| 核心网/公网 | 用户面转发、运营商出口、CDN | 漏掉基站之后不是直接到服务器 |
| 播放器 | 缓冲、解封装、解码、渲染 | 说收到数据就直接显示 |

## 推荐口头回答

> 我先假设手机已经完成 4G/5G 注册并建立了数据会话。用户点开视频后，App 先获得播放 URL，并通过 DNS 把域名解析成 CDN 或服务器 IP。如果使用 HTTPS over TCP，就先做 TCP 三次握手，再做 TLS 握手，然后发送 HTTP 请求；如果使用 HTTP/3，则通常走 UDP 上的 QUIC。
>
> 请求数据经过手机的传输层和 IP 层后交给蜂窝数据接口，Modem 把数据通过空口发到基站；基站把流量送入运营商核心网，再经过承载网和公网到达 CDN 或服务器。服务器返回视频清单和分片后，数据沿反向路径回到 App，播放器完成缓冲、解封装、解码和渲染。如果继续追问“手机怎么先有网”，我会再展开 SIM 鉴权、注册、数据会话以及 IP/DNS/路由配置。
