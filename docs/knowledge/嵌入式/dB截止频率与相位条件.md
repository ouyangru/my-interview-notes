# dB、低通截止频率与相位条件

> 状态：`[weak]`  
> 标签：`[interview]` `[wrong]`  
> 最近复习：2026-09-24

!!! question "面试问题"
    低通滤波器的 `-3 dB` 表示幅度变成多少？低通频响是否存在负频率部分？两个同频信号相差 180° 时，题目中的随机初相是否会改变结论？

## `-3 dB` 先区分幅度比和功率比

同一阻抗条件下，幅度（电压）比使用：

\[
G_{\mathrm{dB}}=20\log_{10}\frac{A_2}{A_1}
\]

功率比使用：

\[
G_{\mathrm{dB}}=10\log_{10}\frac{P_2}{P_1}
\]

因此 `-3 dB` 时：

\[
\frac{A_2}{A_1}=10^{-3/20}\approx0.708\approx\frac{1}{\sqrt2}
\]

\[
\frac{P_2}{P_1}=10^{-3/10}\approx0.501\approx\frac12
\]

面试中说“幅度变成二分之一”是明确错误。准确说法是：**幅度约为原来的 `1/√2`，在阻抗相同的前提下功率约为原来的一半。** 工程里常把一阶滤波器的截止频率称为 `-3 dB` 点；严格说 `1/√2` 对应约 `-3.0103 dB`，口头通常简称 `-3 dB`。

## 一阶低通为什么在截止频率是 `1/√2`

一阶低通的幅频特性可写为：

\[
|H(j\omega)|=\frac{1}{\sqrt{1+(\omega/\omega_c)^2}}
\]

当 `ω = ωc`：

\[
|H(j\omega_c)|=\frac{1}{\sqrt2}
\]

这个结论不是把频率“减半”，而是截止点处的**增益幅值**降到通带增益的约 0.707。

## 低通滤波器到底有没有负频率

这要先问清题目使用哪种频谱表示：

- 在复指数傅里叶变换的**双边频谱**中，负频率是数学表示的一部分。对实信号或实系数 LTI 系统，频谱具有共轭对称性；理想低通通常画成 `|f| <= fc`，包含正、负频率两侧。
- 在工程仪器或教材的**单边幅度谱**中，常只画 `f >= 0`，负频率的信息通过对称性折叠到正频率侧。
- 真实滤波器不会“只因物理频率不能为负就没有负频率响应”；是否画负半轴取决于采用单边还是双边表示。

因此不能机械回答“有”或“没有”。稳妥回答是：

> 如果画双边傅里叶频响，实系数低通在正负频率两侧对称；如果题目明确采用单边幅度谱，就只画非负频率。要先看横轴和定义。

## 相差 180° 的条件不能漏

如果两个信号同频、同幅，并且相位差固定为 `π`：

\[
x_1(t)=A\cos(\omega t+\phi),\qquad
x_2(t)=A\cos(\omega t+\phi+\pi)=-x_1(t)
\]

那么它们逐时刻相消，`x1(t)+x2(t)=0`。这里即使共同初相 `φ` 是随机变量，也不改变“相位差固定为 180°”带来的相消结论。

如果两路幅度不同，则不会完全相消；如果相位差不是固定 `π`，或者两个频率不同，也不能直接得到零。做题时要把“同频、同幅、固定相差 180°”逐项标出来。

!!! warning "我容易答错的地方"
    - `[wrong]` 把 `-3 dB` 的幅度比写成 `1/2`，混淆了幅度和功率。
    - `[weak]` 看到“初相随机”就把两路相位都理解成相互独立随机，漏掉题目已经给出的固定 `180°` 相位差。
    - `[weak]` 不先确认单边/双边频谱，就直接断言低通滤波器没有负频率。
    - `[weak]` 笔试写完后没有用三个 sanity check 自检：`0 dB → 1`、负 dB 应小于 1、幅度平方应对应功率比。

## 推荐口头回答

> `-3 dB` 要先区分幅度和功率。同阻抗下，幅度比用 `20log10`，所以幅度约为原来的 `1/√2`；功率比用 `10log10`，所以功率约为一半。至于负频率，如果题目画双边傅里叶频谱，实系数低通的响应在正负频率两侧对称；单边谱才只画非负频率。相位题里如果两路同频同幅且固定相差 180°，即使共同初相随机也会逐时刻相消，不能把固定相位差漏掉。
