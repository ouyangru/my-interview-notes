# 个人知识库

这里不是原始题库的副本，而是建立在原始资料之上的个人增量层。原始资料尽量保持不动，每次面试、复盘或学习过程中暴露的新问题，都沉淀到这里。

## 维护规则

1. 已有知识点时，优先补充到对应页面，不重复创建近义页面。
2. 新知识点统一按照“面试问题 → 我的理解 → 易错点 → 项目关联 → 继续追问 → 来源”的结构记录。
3. 面试现场出现过的问题必须标记来源，并在对应面试复盘页面建立反向链接。
4. 原始资料与个人理解出现冲突时，不直接覆盖原文，而是在个人知识页中单独说明。
