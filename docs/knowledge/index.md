## 导航规则

左侧“个人知识库”现在由构建脚本自动生成：

- `C++ / 操作系统 / Linux / 网络 / 计算机网络` 归到 **基础知识**；
- `项目复盘 / 嵌入式UI` 归到 **项目与工程**；
- 后续新增 `AI Infra / RDMA / GPU / NCCL / HCCL` 等目录会进入 **AI Infra / 高性能**；
- 新建但尚未配置分类的目录会自动出现在 **其他沉淀**，不会再出现“文件已经在 GitHub 里，但网页侧栏找不到”的情况。

## 维护原则

1. 已有知识点时优先补充原页面，不重复创建近义页面。
2. 新知识点尽量保留“面试问题 → 我的理解 → 易错点 → 项目关联 → 继续追问 → 来源”的结构。
3. 面试现场问题保留来源，并与对应复盘建立双向链接。
4. 原始资料与个人理解冲突时，不覆盖原文，在个人知识页单独记录。

!!! tip "推荐用法"
    面试结束后先写 `interviews/` 复盘，再把长期有价值的问题沉淀进这里。事件历史放复盘，长期知识放知识库，当前薄弱点放 `STATUS.md`。
