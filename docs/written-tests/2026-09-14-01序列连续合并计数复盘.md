## 题目整理

给定长度为 n 的 01 序列。一次操作可以选择任意非空连续子段，用该子段所有元素的整数和替换整个子段；替换结果作为一个新的整数元素，仍可参与之后的操作。操作次数任意，也可以一次都不做。

需要统计最终能够得到多少种不同整数序列，答案对 1000000007 取模。两个序列只有在长度相同且每个对应位置的数值都相同时才算相同。

数据范围：

- 测试组数 1 ≤ T ≤ 100000；
- 单组长度 1 ≤ n ≤ 200000；
- 所有测试组的 n 之和不超过 200000。

## 正确模型

### 1. 反复合并等价于对原序列做连续分段

操作只会合并相邻元素，不会交换顺序，也不会拆开已经合并的内容。

因此，任意最终序列都对应原 01 串的一种连续分段；最终每个整数就是对应原始段中 1 的数量。反过来，任意连续分段都可以逐段合并出来。

问题因此变成：

> 原 01 串有多少种不同的“各段 1 的个数”序列？

注意不同分段可能产生同一个数值序列，所以不能直接统计切割方案数。

### 2. 用 1 之间的零间隙描述最终序列

假设字符串共有 m 个 1，依次记：

- z0：第一个 1 前面的零数；
- zi：第 i 个和第 i+1 个 1 之间的零数，1 ≤ i < m；
- zm：最后一个 1 后面的零数。

开头 z0 个零最终可以保留 0 到 z0 个零元素，贡献 z0+1 种。结尾同理，贡献 zm+1 种。

对于内部某对相邻的 1，中间有 z 个零：

1. 不在这两个 1 之间切开：两个 1 最终属于同一个正整数，贡献 1 种；
2. 在它们之间切开：中间最终可以保留 0、1、……、z 个零元素，共 z+1 种。

因此这个内部间隙总贡献为：

z + 2

特别地，当 z=0 时仍有两种：

- 不切，11 变成同一段中的 2；
- 切开，得到相邻的 1,1。

所以贡献是 2，而不是 1。

### 3. 总公式

如果字符串全是 0，最终只能得到长度为 1 到 n 的全零序列，因此答案为：

ans = n

如果至少有一个 1，则：

ans = (z0+1) × (zm+1) × Π(zi+2)

其中乘积遍历所有相邻 1 之间的内部零间隙。

若 1 的下标为 p0,p1,…,p(m-1)，使用 0 基下标，可以直接写成：

ans = (p0+1) × (n-p(m-1)) × Π(pi-p(i-1)+1)

### 4. 多个连续 1 和远处零间隙

例如 111001：

- 前两个相邻 1 之间没有零，贡献 2；
- 第二、第三个相邻 1 之间没有零，贡献 2；
- 第三、第四个 1 之间有两个零，贡献 4。

总数为 2×2×4=16。

连续的多个 1 不需要单独讨论：每多一个 1，就多一个“切或不切”的内部间隙。

## 不重不漏说明

每个最终序列中的正整数部分，唯一确定了 m 个 1 被分成了哪些连续组，也就唯一确定了哪些相邻 1 之间被切开。

在每个已经切开的零间隙中，最终出现多少个零元素，也能从最终序列唯一读出。虽然零可以用多种原始切割方式分配到左右正数段，但这些方式产生的是同一个最终数值序列，本公式只按“最终保留几个零元素”计数一次。

因此，不同因子选择对应不同最终序列；任意合法最终序列也一定对应其中一组选择，计数不重不漏。

## C++11 实现

~~~cpp
#include <bits/stdc++.h>
using namespace std;

const long long MOD = 1000000007LL;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;

    while (T--) {
        int n;
        string s;
        cin >> n >> s;

        long long answer = 1;
        int firstOne = -1;
        int lastOne = -1;

        for (int i = 0; i < n; ++i) {
            if (s[i] != '1') {
                continue;
            }

            if (firstOne == -1) {
                firstOne = i;
                answer = i + 1;
            } else {
                answer = answer * (i - lastOne + 1) % MOD;
            }
            lastOne = i;
        }

        if (firstOne == -1) {
            cout << n % MOD << '\n';
        } else {
            answer = answer * (n - lastOne) % MOD;
            cout << answer << '\n';
        }
    }

    return 0;
}
~~~

## 复杂度

- 单组时间复杂度：O(n)；
- 空间复杂度：O(1)；
- 所有测试组总时间复杂度：O(Σn)，符合 Σn≤200000。

## 暴露的知识点和错误类型

1. **等价模型识别不稳定**：看到可以反复操作，容易考虑操作过程，没有先问最终状态等价于什么静态结构。
2. **计数对象未先定义**：需要统计的是不同最终数值序列，而不是不同切割方式。
3. **乘法原理推广不稳定**：理解单个间隙后，没有马上把多个 1 看成多个独立间隙。
4. **连续 1 的边界含义不清**：中间没有零并不代表没有选择，仍然存在“切开/不切开”两种。
5. **看懂尚不等于掌握**：当前结论来自讲解，尚未进行新的换皮题独立推导。
