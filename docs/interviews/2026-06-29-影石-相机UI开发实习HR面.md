#### 5. 当时回答的问题在哪里

- **正确的部分：**主动问培养流程、是否有小需求 / 小项目、后续流程，说明你关心实际上手和流程推进。
- **错误的部分：**“1～2 个月时是否会安排小项目”略显被动，容易让 HR 觉得你期待系统培养；可以改成“我希望尽快熟悉框架后承接小需求”。
- **遗漏的关键点：**可以补一句“我也会主动看文档和代码，不完全依赖导师手把手带”。
- **表达/结构问题：**问题本身太长，HR 面提问应更短更清晰。
- **如果我是面试官，为什么会继续追问：**HR 会担心你是否需要大量带教，或者能否自主学习。

## 本场整体表现

### 做得比较好的部分

- HR 面整体通过，说明岗位意愿、实习时长、地点倾向和沟通态度没有形成致命问题。
- 能把影石相机业务和自己的 V853 摄像头采集 / 视频传输项目联系起来，这是本场最有效的匹配理由。
- 对经纬恒润实习的结束原因给出了真实解释：日常实习无转正机会 + 中期答辩。
- 对加班、优先级、实习培养流程的回答总体没有明显价值观冲突。

### 最影响结果的问题

1. **HR 面稳定性表达需要更稳。**尤其是解释上一段实习结束、当前其他 offer、能实习多久时，要主动消除“只做三四个月就走”的疑虑。
2. **岗位动机要更凝练。**影石的匹配点是相机业务、摄像头采集、视频流、设备端 UI 状态逻辑，不要让 OS 项目类比抢走重点。
3. **行为问题回答要先给判断标准。**优先级和加班问题不能只讲经历，要先给原则，再给例子。

### 表达层面

- 是否经常没有先给结论：有。比如优先级、加班、实习离职原因都可以更早给结论。
- 是否展开过多：有。自我介绍中 OS 项目和 UI 类比、加班中“无意义加班”的展开偏长。
- 是否把“我不知道”之后的推理讲清楚：本场不是主要问题。
- 项目题是否体现“问题 → 设计 → trade-off → 极端情况”：HR 面没有深挖，但 V853 成就感题可以更自然地讲“看见画面异常 → 拆链路定位 → 调整方案”。
