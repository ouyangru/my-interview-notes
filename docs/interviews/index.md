# 面试复盘

这里保存每一次真实面试的现场记录，重点记录“被问了什么、当时怎么答、哪里答得不完整、最后应该沉淀到哪个长期知识点”。

建议文件名统一使用：`YYYY-MM-DD-公司-岗位.md`，例如 `2026-09-15-某公司-嵌入式软件.md`。

## 复盘流程

1. 先把面试问题按实际顺序写下来，不急着整理成标准答案。
2. 对每道题标记：答对 / 不完整 / 答错 / 不会。
3. 只把值得长期复用的问题沉淀到 [个人知识库](../knowledge/index.md)。
4. 在面试复盘和知识页之间互相建立链接，方便以后从“某次面试”跳到“某个知识点”。
